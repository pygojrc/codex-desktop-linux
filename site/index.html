HOW IT WORKS

小而明确的兼容层

项目只负责把官方 Linux 桌面应用整理成适合 Manjaro KDE 安装的包，并处理一个输入法启动环境问题。

01 / PACKAGE
▣

沿用官方应用运行时

构建脚本下载 OpenAI 官方的 chatgpt_amd64.deb，提取数据文件并重新打包为 pacman 格式。仓库不包含第三方应用源码。

官方 .debpacmanx86_64
02 / INPUT
⌨

为 Fcitx5 设置启动环境

启动器设置 GTK_IM_MODULE=fcitx 和 XMODIFIERS=@im=fcitx，再启动官方程序入口。

查看实现说明 ↗
03 / VERIFY
✓

校验后再构建发布

CI 从官方 APT 包索引读取版本与 SHA-256；下载的包通过校验后才进入构建和 GitHub Release 流程。
